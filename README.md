# CGNiksCustomRopeVariants
This mod adds several new rope materials, all of which can be found as loot.  
This mod needs to be on both the Client and Server.  
Requires https://github.com/Circl-NoE/ATTMateriaLib, https://github.com/CG-Nik/DifferentRopeMaterials, and https://github.com/CG-Nik/CustomDistributionAPI; all on the Server and Client.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
